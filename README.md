# 📊 Sales & Profit Analysis Dashboard - Excel

An interactive **Sales & Profit Analysis Dashboard** created using Microsoft Excel to analyze sales and profit performance from a given dataset.

## 📌 Project Overview

The goal of this project was to transform raw sales data into meaningful insights using Excel's data analysis and visualization features.

The dashboard provides an overall view of sales, profit, customers, categories, states, and monthly performance.

## 🔍 Key Analysis

The dashboard includes the following analysis:

- 💰 Total Sales
- 📈 Total Profit
- 📊 Profit by Year
- 🏷️ Sales by Category
- 👥 Customer Count by Year
- 🗺️ Sales by State
- 📅 Sales by Month
- 🏆 Top 5 Customers by Profit

- Microsoft Excel
- Pivot Tables

- Slicers
- Data Analysis
- Data Visualization

## 📁 Workbook Structure

The Excel workbook contains three main sheets:

### 1. `data`
Contains the raw sales dataset used for the analysis.

### 2. `pivot_table`
Contains the Pivot Tables created from the dataset to summarize and analyze the data.

### 3. `DASHBOARD`
Contains the final interactive Sales & Profit Dashboard with charts, KPIs, and filters.

## 🎯 Project Objective

The main objective of this project was to:

- Analyze overall sales and profit performance.
- Identify sales trends across different years and months.
- Understand category-wise and state-wise sales.
- Identify top customers based on profit.
- Present the findings through an interactive and easy-to-understand dashboard.
